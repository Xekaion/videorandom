# 1.9.38 · 긴 영상 재분석과 뒤쪽 자막 복구

CRPD-180의 앱 기술 진단 2,404건을 연결하고 이관 중복을 제외한 전체 분석 7회를 확인했다. 한국 시각 기준이며, 미디어·대사·응답 본문은 확인하지 않았다.

|---|---:|---|

| 10/24 19:03 | 632 | 첫 번역 묶음의 제공자 오류. 당시에 세부 원인 미기록; 0/632 |
| 10/27 18:34 | 진행 중 501 | 음성 인식 중 취소. 취소 주체 미확인 |

최신 음성 업로드는 약 145MB 전부 접수됐다. 인식은 31분 15초 뒤 완료 이벤트를 남겼으나, 당시 기술 로그에는 음성 길이·처리 범위·마지막 대사 시각·누락 검사 수가 없었다. 구간 수 자체로 원문 누락이나 전체 음성 처리 여부를 단정할 수 없다. 최근 두 작업의 종료 뒤 다음 대기 작업 시작을 확인했다. 최신 로그에 SRT 저장 실패는 없었으나 저장 성공 여부는 기록만으로 확인할 수 없다.

- 번역 계획이 원문 구간 수와 영상 길이를 같이 사용한다. 1시간 이상 또는 원문 960구간 이상이면 최대 32구간과 4,800 코드 단위를 적용한다. 원문 ID, 시간, 내용은 그대로다.
- 확인된 앱 시간 초과로 원래 두 묶음에 새 검증 자막이 없으면, 아직 시도하지 않은 뒤쪽 번호에서 최대 16구간, 다시 시간 초과되면 최대 8구간의 짧은 요청을 시도한다. 각 요청 제한은 최대 1분이다. 뒤쪽이 응답하면 이어서 처리하고 앞쪽 빈 구간도 기존 보완으로 넘긴다. 확인 요청도 연속으로 실패하면 검증된 결과만 보존하며 방문하지 않은 구간을 완료로 표시하지 않는다. 인증·거절·저장 오류와 취소의 기존 처리는 유지한다.
- 도중에 중단된 원문 접두부는 기존 관련 원문을 목록에서 대체하지 않는다. 전체 음성이 처리된 결과는 구간 수 감소나 별도 누락 검수 및 번역 오류만으로 숨기지 않는다.
- 새 원문 인식의 기술 기록에 영상·디코딩·실제 처리 시간, 마지막 대사, 처리·검수 여부 및 확인할 구간 수를 남긴다. 수치 없는 예전 완료 신호로 전체 범위를 추정하지 않는다.
- 과거 형식 불일치의 행별 검증·보완과 SRT `EISDIR` 대체 이름 저장은 기존 수정으로 유지한다. 과거 미분류 제공자 오류와 취소 주체를 추정하거나 실제 제공자 장애를 무한히 반복하지 않는다.

검증에는 소유한 모의 제공자와 임시 저장소만 사용한다. 연속 시간 초과 뒤 정상 응답이 돌아와 뒤쪽 자막을 보관하고 이전 빈 구간까지 완료하는 경우, 계속 무응답인 경우, 원문 기술 진단, 중단된 원문 우선순위와 오래된 기록 호환을 검사한다. 실제 CRPD-180을 다시 실행하지 않는다.
