# 1.9.19 · 내용 검증 문제 구간을 남기고 마지막 구간까지 처리

2026-10-21. 실제 실패 확인은 기술 진단의 코드·단계·개수·버전만 읽었다. 사용자 영상·음성·대사·요약·제공자 원시 응답은 읽지 않았다. 구현 검증에는 중립 합성 전사·가짜 제공자·별도 저장소와 시험 실행 파일만 사용한다. 운영 서버·설정·작업·결과를 변경하거나 실제 모델·번역 제공자를 호출하지 않는다.

## 확인한 중단 경로

최근 번역 복구의 기술 기록에서 확보한 원문 1,819구간 중 864구간을 보관한 뒤, 881–960번 초안 묶음에서 `SUBTITLE_BATCH_INVALID`로 종료된 것을 확인했다. 요청 PC는 1.9.17, 분석 서버는 1.9.16이었다. 사용자가 보고한 ‘번역되지 않은 외국어’ 메시지를 내는 검증 함수는 한 대사라도 해당 조건이면 묶음 전체에 예외를 던졌다. 누락·길이 문제만 분리하던 경로에서 외국어 대사를 분리하지 않았다. 진단 코드만으로 실제 반환 대사의 내용을 추정하지 않으며 개인 파일명·경로·식별자·시각은 공개 문서에서 생략한다.

기존 코드는 모든 구간을 순회한 뒤 일부 미승인이 남은 결과도 번역 복구 실패로 표시했다. 사용자에게 중간 중단과 마지막까지 처리한 부분 결과의 차이가 드러나지 않았고, 자동 대기열도 이 결과에서 멈췄다.

## 변경과 보존

- 이미 존재하는 외국어 판정에 `SUBTITLE_FOREIGN_TEXT`를 부여한다. 응답의 명시적 번호·중복·범위·형식을 먼저 검증하고 그 번호의 외국어 대사만 분리한다. 정상 대사는 원래 ID·시각으로 보관한다. 번호가 틀린 대사를 위치로 추정해 맞추지 않는다.
- 분리한 대사만 기존 20구간 이하 보완과 작업당 64회 공용 한도로 요청한다. 보완 뒤에도 외국어가 남으면 미완료로 두고 다음 묶음으로 진행한다. 정확 모드는 유효한 초안 번호만 원문 대조 검수에 보낸다. 모두 외국어인 묶음은 빈 검수 요청을 만들지 않고, 검수하지 않은 초안의 새 이름 표기도 다음 묶음이나 체크포인트로 넘기지 않는다. 이전에 검수한 표기는 유지한다.
- 외국어 대사는 승인·체크포인트·한국어 자막에 넣지 않는다. 승인한 앞뒤 대사를 부분 SRT에 원래 시각으로 보관한다. 미승인 번호는 빈 구간이고, 다음 복구는 해당 번호만 요청한다. 승인 대사가 하나도 없으면 빈 SRT를 만들지 않는다.
- 전체 순회와 체크포인트 저장을 끝낸 결과만 `processingComplete: true`, `processedCues: 전체 원문 수` 증거를 가진다. 이 증거는 한국어 번역 완료 증거와 다르다. `complete`와 `translationComplete`는 false, 결과와 번역 복구 상태는 partial, 진단은 부분 처리 경고로 남긴다. 저장한 검증 대사를 재사용하더라도 과거 처리 완료 증거를 새 시도의 증거로 가져오지 않는다.
- 서버 내부에서 생성한 비공개 표식으로만 해당 부분 결과를 분류한다. 제공자·저장·취소 실패 시 처리 완료 증거를 제거한다. 서비스 거절·인증·한도·503·시간 초과·연결 오류·잘못된 JSON·중복/범위 밖 번호·유효하지 않은 구조·용어 충돌은 이 경로로 바꾸거나 재시도하지 않는다.
- LAN 전송과 목록 투영은 원문 지문·개수·부분 자막 번호·ID·시각·상태·진단을 검증한 처리 완료 정보만 보낸다. 오류와 충돌하는 증거는 제거한다. 한국어 번역 완료를 새로 승인하지 않는다. 이전 완성 자막·원문·줄거리·이미지와 연결 설정은 유지한다.
- 대기열에는 별도의 비차단 부분 결과 판정을 사용한다. 원문 전체 처리 증거 또는 유효한 완성 원문, 줄거리와 저장 결과가 확인된 경우 다음 영상으로 넘어간다. 실제 원문 처리·요약·SRT 저장·제공자 오류는 계속 대기를 중지한다. 기존 사용자 중지·과거 실패·중단 복구 대기를 자동 해제하거나 실패 요청을 재제출하지 않는다.
- 화면은 전체 처리 완료와 미번역 `N/M`, 실제 중단을 구분한다. 저장한 대사가 N/N이어도 이번 시도의 최종 검수 증거가 없으면 확인 필요로 유지한다. 새 전체 한국어 분석에서는 이전 번역 복구의 실패 상태를 제거하고 이번 시도의 상태를 사용한다.
- 모델·프롬프트 버전 7·검수 횟수·보완 한도·타임아웃과 원문 처리 기준은 유지한다. 이 업데이트가 실제 사용자 영상의 번역을 완료했다는 뜻은 아니다.

## 합성 검증

- 외국어 구간 회귀 61개: 정확 모드의 compact/기존 검수, 빠름·초고속, 초반·중간·마지막 외국어, 2,019구간 마지막까지 진행, 미완료 번호만 복구, 보완 한도, 전부 미승인일 때 빈 파일 방지, 취소 및 서비스·구조 오류 즉시 중단을 확인한다. 검수한 앞부분·외국어만 남은 묶음·정상 뒤쪽을 연결해 기존 검수 용어만 후속 요청과 체크포인트에 남는지도 확인한다.
- 처리 결과·LAN·대기열 검사 45개: 원문 지문·시각·ID·개수·증거 오류를 거부하고, 0개 승인·보관 N/N 미검수·부분 SRT·확인 구간 이후 다음 영상 진행과 기존 일시 중지 보존을 확인한다. 원문 처리 증거 부족·거절·네트워크·요약·파일 저장 오류는 계속 대기를 중지한다.
- 새 UI 검사와 진단 검사는 전체 처리 완료 표시·실제 빈 구간 개수·잘못된 완료 증거·서비스 오류·번역 완료와의 혼동 방지 및 실제 제공자 호출이 없는 표시를 검증한다. 기존 누락·길이 문제의 검사는 전체 순회한 부분 결과만 새 상태 계약에 맞추며, 구조·제공자 오류의 실패 기대는 유지한다.
