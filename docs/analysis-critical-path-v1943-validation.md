# 1.9.43 · 음성 인식과 번역의 대기 시간

2026-11-18. 저장된 기술 시각의 최근 장편 두 사례에서는 음성 인식에 약 44분과 38분, 번역에 약 46분과 23분이 걸렸다. 음성 시간에는 모델 시작, 첫 처리, 누락 재검사가 포함된다. 이 수치는 당시 v1.9.40의 실제 기록이다. 파일명과 자막 내용은 확인하지 않았다.

- 정확 모드에서 기존 디코딩 스레드가 같은 PCM과 발화 검출 옵션으로 CPU Silero 검사를 바로 실행한다. 호출 스레드에서는 같은 Whisper 모델을 로드한다. CUDA에서는 파형의 별도 NumPy 검사를 첫 음성 인식과 겹쳐 실행하고, 결과는 기존 위치에서 받아 재검사에 쓴다. 음성 범위, 정렬, beam, 재검사 입력, 경계와 누락 판정은 기존대로 유지한다.
- 960구간 이상이거나 1시간 이상인 정확 모드 자막은 32구간으로 시작한다. 초안과 독립 검수 모두 시작 신호를 받았고 1.2–12초 사이에 정상 응답한 완전한 묶음 4개마다 48, 64까지 한 단계씩 커진다. 느린 응답, 재연결, 혼잡, 시간 초과, 형식 보완 또는 검증되지 않은 구간이 생기면 32로 돌아간다. 전송을 시작한 초안 한 개는 원래 구간 경계를 갖고 완료한다. 이후 요청부터 새 크기를 사용한다. 정확 모드의 원문 대조와 기존 시간 초과 복구는 유지된다.
- 묶음 크기가 바뀌면 모델에 함께 들어가는 문맥도 달라지므로 실제 모델의 표현이 이전과 동일하다고 가정하지 않는다. 회귀 검사는 번호·시간·번역과 검수의 전 범위·저장·대기열 순서 및 강제 종료 계약을 확인한다.

| 시험 | 이전 | 변경 후 |
|---|---:|---:|
| 1,321구간 번역 및 검수 요청 수 | 84회 | 50회 |
| 같은 번역 경로의 경과 시간 | 3.37초 | 2.07초 |
| 음성 인식 첫 호출 시각 | 1.30초 | 0.68초 |
| 같은 음성 작업 경과 | 2.95초 | 2.31초 |

번역은 요청 크기에 따른 지연을 넣은 중립 모의 CLI, 순서를 교차한 4회 중앙값이다. 양쪽 모두 1,321개를 정확히 한 번씩 번역하고 한 번씩 독립 검수해 같은 결과와 시각을 냈다. 음성은 중립 파형 300초, 실제 CPU Silero와 NumPy, 같은 지연의 모의 Whisper를 사용한 순서 교차 5회 중앙값이다. 18번의 디코딩 요청과 이벤트·시각·검수 출력이 일치했다. 실제 장편 영상의 단축률과 외부 모델 응답 시간은 새 배포에서 측정하지 않았다.

측정은 `artifacts/benchmark-response-v1943.log`, `artifacts/asr-overlap-v1943-benchmark.json`에 기록했다.

자동 테스트 3,314개 중 3,313개 통과, 1개 건너뜀. 격리된 Windows 실행 파일에서 1.9.43 버전, 자막 번역 복구, 원문 타임코드 보존 및 영상 옆 SRT 저장을 확인했다.
