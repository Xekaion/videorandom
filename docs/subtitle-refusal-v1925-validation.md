# 1.9.25 · 일반 대사 거절 오탐과 영상별 대기열 분리

2026-10-24. 실제 영상·음성·대사·원시 번역 응답을 읽거나 실제 Codex 추론·번역·ASR을 호출하지 않았다. 중립 합성 대사·가짜 CLI·별도 저장소로 검사한다. 운영 프로그램·분석 작업·연결 설정은 중지·교체·재시작하지 않는다.

## 확인한 문제

한국어 거절 판정의 첫 두 정규식은 요청 지시어 `이`를 단어 경계 없이 찾았다. 합성 대사 `그 둘이 번역할 수 없어. 새 통역사를 불러 줘.`, `수진이 번역할 수 없어. 오늘은 사무실에 없거든.`의 주어 끝에서도 조건이 맞아 정상 대사를 작업 거절로 오인했다. 해당 두 접두어에만 유니코드 문자·숫자·밑줄 경계를 추가했다. 영어·정책 관련 거절 분기와 명시적인 응답 거절 필드는 유지한다.

별도로, 성공적으로 받은 자막 응답에 대한 영상별 거절 판정이 공유 제공자 오류로 분류되어 다음 독립 영상의 대기열까지 정지했다. `SUBTITLE_PROVIDER_REFUSAL`+`response-field`, `SUBTITLE_REFUSAL_TEXT_DETECTED`+`subtitle-text`라는 정확한 코드·출처와 프로그램이 생성한 문장이 대응하는 경우에만 영상별 결과로 처리한다. 확보한 결과·진단·부분 SRT를 저장한 뒤 해당 시도를 기록하고 다음 독립 영상을 진행한다. 거절한 영상의 요청을 재시도하거나 남은 구간을 계속 보내지 않는다.

기술 진단만 조회한 최근 한 작업은 원문 1,354구간 중 검증한 한국어 1,232구간을 저장했고, 클라이언트는 1.9.24·분석 서버는 1.9.23이었다. 실제 응답 내용은 검사하지 않았으므로 이 작업이 위 오탐에 해당하는지 실제 서비스 거절인지는 확정하지 않는다. 이 릴리스가 해당 영상의 번역을 완료했다는 뜻도 아니다.

## 유지하는 처리와 보호 조건

- 자막 배열과 검수의 원시 수정 행은 알 수 없는 번호·중복 행을 걸러내기 **전에** 거절 여부를 검사한다. 무효한 번호 속의 거절 문장을 버리고 정상 결과로 승인하지 않는다.
- 실제 요청 거절은 현재 번역·검수 요청을 중단하고 오류·이전 검증 결과를 보관한다. 거절을 숨기거나 같은 요청을 재시도·재표현·모델 변경으로 우회하지 않는다. 제공자 거절의 구체적인 이유를 응답 증거 없이 추정하지 않는다.
- 실행 단계 `PROVIDER_REFUSAL`, 알 수 없는 거절, 출처 불일치·누락, 다른 오류가 덧붙은 메시지는 공유 오류로 유지한다. 인증·실제 사용량·혼잡 한도 소진·통신·시간 초과·저장·취소 증거는 영상별 코드보다 우선한다.
- 다음 영상 진행은 현재 시도의 결과와 종료 기록이 저장된 뒤에만 적용한다. 기존 일시 중지 복원도 정확히 대응하는 저장 결과에서 영상별 문제임을 확인한 경우에만 적용하고, 앞선 시도는 소비해 재요청하지 않는다. 사용자 중지·취소·저장되지 않은 중단 상태는 유지한다.
- 원래 번호·ID·시각·독립 원문 대조 검수·완료 증거와 부분 SRT를 유지한다. 원문/한국어 개수 차이·잘못된 행·외국어·짧은 대사의 기존 분리 및 제한된 보완 처리는 유지하며, 미완료를 완성으로 바꾸지 않는다.
- 거절 판정 의미 변경에 맞춰 번역 계약을 10으로 올린다. 기존 3~9 체크포인트는 동일 원문 지문·번호·시각·프로필·검수 증거를 재검증해 재사용하며 거절도 다시 확인한다. 검증하지 않은 구간을 캐시만으로 승인하지 않는다.
- 1.9.24의 GPT-6 Luna / Low / Standard 지정과 명확한 모델 혼잡에만 적용하는 제한된 대기를 유지한다. 새 모델·추가 실제 제공자 요청은 도입하지 않는다.
- 잘못된 JSON·최상위 응답 구조·용어 정보 충돌은 정상 자막으로 승인하지 않는다. 요약 형식 실패와 번역 시작이 연결된 기존 처리도 그대로이며, 이 릴리스가 준비된 모든 오류 경로를 없앴다고 주장하지 않는다.

실제 서비스는 구조화된 응답에서도 거절을 반환할 수 있다. [공식 Structured Outputs 안내](https://developers.openai.com/api/docs/guides/structured-outputs)의 거절 처리와 같이 정상 자막과 구분해야 하며, 모든 서비스 거절·인증·디스크·통신 오류를 없애겠다는 보장은 하지 않는다.
