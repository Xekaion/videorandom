# 1.9.3 · 번역 묶음의 누락 구간 보완

2026-10-18. 한국어 번역 서비스가 요청한 자막 묶음 중 일부만 반환하여 개수 검증에서 중단되는 경우를 보완한다. 이번 변경은 응답 형식과 누락된 번호의 제한적 보완에 적용한다. 원어 음성을 다시 인식하거나 원문·자막 시각을 추정하여 채우지 않는다.

## 응답 개수·번호와 순서

각 요청의 JSON 스키마에 자막 배열의 정확한 개수와 허용하는 원문 번호를 지정한다. 응답을 받은 뒤에도 실제 개수·번호·본문·용어를 검증한다. 순서만 바뀐 응답은 원문 번호에 맞춰 정렬한다. 중복 번호, 요청 범위를 벗어난 번호, 초과 응답을 정상 묶음으로 받아들이지 않는다.

배열의 `minItems`·`maxItems`와 번호의 `enum`은 [OpenAI의 Structured Outputs 지원 스키마](https://developers.openai.com/api/docs/guides/structured-outputs)에 맞춘다. 실제 외부 제공자 호출 대신 요청 파일의 개수·허용 번호를 모의 실행에서 검사했다.

기본 번역 묶음은 기존과 같은 80구간이다. 속도 우선·정확도 우선의 기본 검수 횟수와 기존 생략·한국어·용어 검증 기준, 원어 인식 모델·전체 음성 범위·단어 시각·재검수 방식은 바꾸지 않는다.

## 누락 보완의 조건과 상한

최초 응답이 비어 있지 않고, 반환한 자막의 번호·본문·용어 등 기존 검증을 통과한 경우에만 빠진 번호를 구한다. 누락 번호를 최대 20개씩 나누어 각각 한 차례 보완 요청한다. 기본 80구간 묶음의 각 단계에서 추가 요청은 최대 4회이며, 한 번의 번역 작업 전체에서 누락 보완 요청은 총 64회로 제한한다. 이 상한은 다른 검수 절차의 횟수를 늘리는 설정이 아니다.

초안 응답이 일부 누락되면 누락된 초안만 요청하여 합친 뒤, 정확 모드에서는 기존 방식대로 전체 묶음을 검수한다. 검수 응답이 일부 누락되면 해당 원문·초안의 누락 번호만 검수하여 합친다. 이미 반환된 정상 구간을 전체 묶음으로 다시 요청하지 않는다. 합친 응답도 전체 번호·개수·본문·용어를 다시 검증한 뒤에만 저장한다.

보완 응답의 누락은 다시 보완하지 않는다. 중복·초과·범위 밖 번호, 외국어가 남은 잘못된 번역, 용어 충돌, 빈 배열, 자막 배열이 없는 응답, 제공자의 요청 거절, 인증·사용량·연결·서비스 오류는 보완 대상으로 바꾸지 않고 중단한다. 완료 전에 검증한 앞부분과 원래의 대사·시각은 기존 보존 규칙에 따라 남긴다. 잘못된 응답을 임의의 대사나 빈 자막으로 채워 완료로 표시하지 않는다.

## 이전 번역 진행 기록

번역 요청·스키마·검증 규칙의 버전을 5로 구분한다. 버전 3·4에서 검수하여 저장한 체크포인트도 조건이 일치하면 다시 사용할 수 있다. 대상 언어, 품질 설정과 검수 횟수, 전체 원문 구간 수와 지문, 연속된 번호, 원문 ID와 시작·종료 시각, 한국어 본문과 생략 의심 여부, 용어 충돌을 다시 확인한다.

검증을 통과한 가장 긴 앞부분만 이어 사용하고 새 진행 기록은 버전 5로 저장한다. 파일명 유사도나 저장 날짜만으로 다른 원문의 번역을 재사용하지 않는다. 검증되지 않은 이전 초안이나 잘못된 체크포인트는 완료한 번역으로 승격하지 않는다. 사용자가 전체 번역을 새로 요청하는 선택은 기존 방식대로 처리한다.

## 업데이트와 적용

Windows EXE 1.9.0 이상에는 내장 업데이트가 있다. 상단 **업데이트 → 새 버전 확인 → 업데이트 다운로드 → 업데이트 적용**을 사용할 수 있다. 자동 적용이 켜져 있으면 시작 후와 약 5분 간격으로 새 버전을 확인하고, 다운로드·검증을 마친 뒤 분석·번역·업로드·저장이 끝나는 시점에 적용한다. 분석 결과·자막·서버 주소·연결 코드는 같은 사용자 데이터 폴더에 보관한다. 이 버튼은 현재 접속한 프로그램을 업데이트하며 다른 PC의 별도 서버 프로세스를 교체하지 않는다.

1.9.0 이전 EXE는 처음 한 번 새 실행 파일로 교체해야 내장 업데이트를 사용할 수 있다. `분석서버_시작.bat`의 Node 소스 실행에는 자동 소스 다운로드·교체가 없으므로 서버를 새 코드로 다시 실행해야 한다. 새 실행 파일이나 소스를 내려받은 것만으로 이미 실행 중인 이전 서버의 처리 방식이 바뀌지는 않는다.

이번 번역 개선은 실제 번역을 맡는 PC가 새 버전으로 시작한 분석·번역 복구부터 적용한다. 이전 결과의 미번역 구간을 자동으로 완성 처리하거나 기존 사용자 영상의 번역 완료를 보장하지 않는다.

## 검증 범위

검증 자료는 합성 원문·모의 번역 응답·독립 임시 데이터 폴더를 사용한다. 실제 사용자 영상·대사·이미지나 외부 번역 제공자를 호출하지 않으며 운영 서버를 중지하거나 재시작하지 않는다.

확인 항목은 정확한 개수·허용 번호의 요청 스키마, 응답 순서 정규화, 초안과 검수 각각의 누락 번호만 보완, 보완 응답에 대한 재귀 금지와 작업별 상한, 잘못된 응답·거절·서비스 오류의 중단, 이전 버전 체크포인트의 엄격한 재검증, 원문·시각·검수된 앞부분 보존이다.
