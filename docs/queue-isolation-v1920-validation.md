# 1.9.20 · 영상별 미완료와 대기열 중지 분리

2026-10-21. 구현 검증은 중립 합성 결과·가짜 분석 엔진·별도 저장 폴더와 시험 실행 파일만 사용한다. 운영 서버·작업·설정·실제 영상과 번역 서비스는 변경하거나 호출하지 않는다.

## 원인과 변경

기존 대기열은 한 영상의 완성 여부를 다음 독립 영상의 실행 조건으로 사용했다. 1.9.19는 전체 구간을 순회한 특정 부분 자막만 예외로 허용했기 때문에, 원어 확인이나 자막 검증이 남으면 다음 영상까지 일시 중지됐다.

- 저장된 결과의 문제 범위를 별도 정책으로 판단한다. 자막 개수·번호·형식·길이·외국어·미번역·원어 확인, 빈 요약, 특정 영상 형식과 경로 문제는 결과를 보관하고 다음 파일로 진행한다. 이 판단은 해당 결과나 자막을 완성으로 승인하지 않는다.
- 서비스 거절·인증·한도·503·연결·시간 초과·도구 누락·공통 저장·취소 및 알 수 없는 실제 오류는 다음 작업에도 영향을 주므로 계속 중지한다. 영상별 오류 문구 뒤에 공통 오류가 붙거나 과거 진단이 남아 있어도 공통 오류가 우선한다. 중단한 서비스 요청을 자동 재시도하지 않는다.
- 각 시도의 건너뜀 표식을 결과 JSON과 함께 저장한다. 대기열 표시에서는 경로별 최상의 결과와 별개로 저장된 시도를 모아 최신 20건·전체 개수·파일명·고정 사유·자막 N/M·시각을 표시한다. 그 시도의 정확한 ID로 상세를 읽으며 기존 완성 결과를 대체하지 않는다.
- 자동 뽑기에도 실행 전 시도 ID를 저장한다. 재실행 시 동일 ID·경로의 내구성 있는 결과를 확인해 소비하므로 같은 실패 파일을 자동 재분석하지 않는다. 결과가 없는 중단 시도는 명시적인 재개가 필요하다. 저장 실패 시 해당 항목을 소비하지 않는다.
- 대기 중 원본이 사라지거나 복구 대상이 변경되면 분석 엔진 호출 없이 실패 결과와 사유를 먼저 저장한 뒤 건너뛴다. 이 과정에서 저장 실패가 나면 대기열을 중지하고 원래 항목을 보존한다.
- 구버전의 `attempt-failed` 일시 중지는 정확한 저장 결과 ID·경로가 영상별 문제로 확인되는 경우에만 해제한다. 사용자 일시 중지·취소·중단·알 수 없는 이유·공통 오류는 유지한다. 기존 주소·연결 코드·원문·요약·자막·이미지를 변경하는 업데이트가 아니다.

## 검증

- 최종 전체 Node 검사 **1,562개 통과**, 실패·취소·생략 0개, 40.41초. `artifacts/test-v1920-final.log`. 앞선 실행에서는 기존 성능 검사에서 GC에 따른 순간 힙 측정 초과가 한 번 발생했고 별도 5개 검사와 최종 전체 검사에서 통과했다. 또 별도 시험 서버의 OS 임의 포트가 `fetch`의 포트 제한에 걸려 기존 시험 HTTP 호출을 공용 네이티브 HTTP 도우미로 통일했다. 저장·재분석·자막 다운로드 관련 **17개 검사**도 다시 통과했다. 이 변경은 제품의 네트워크 설정이나 보안 정책을 바꾸지 않는다.
- 새 정책·이력 수집·화면 검사 **69개**, 새 서비스 통합 시나리오 **42개**를 통과했다. 연속 미완료, 자동·수동·복구 대기, 실제 합성 부분 SRT 저장, 파일 없음·변경, 사용자 중지, 공통 오류 우선, 원시 오류 내용 비노출을 확인한다.
- 관련 대기열 회귀 **152개**가 24.92초에 통과했고 별도 기본 서비스 검사 **8개**도 통과했다. 재실행 후 같은 요청을 재제출하지 않는 것, 다른 중단 시도가 남으면 과거 파일별 중지를 자동 해제하지 않는 것, 기존 시각과 더 최신 결과의 선택 순서를 보존하는 것을 포함한다. `artifacts/test-v1920-queue.log`, `artifacts/test-v1920-service.log`.
- Windows EXE 빌드와 manifest 검증을 통과했다. **99,531,759바이트**, SHA-256 `fc3a8917528536a6331695cedd2683740d3c592c10f051b777f120d568a5e65a`. 이전과 같은 Windows 미사용 `open/xdg-open` 포함 경고만 남았다. `artifacts/build-v1920.log`.
- 최종 EXE를 별도 저장소와 소유한 시험 포트에서 실행해 HTML·JS·CSS 일치, LAN 부분 결과·원래 ID와 시각·부분 SRT·기존 완성 SRT 보존·거절과 시간 초과 진단 회귀를 통과했다. 새 건너뜀 표식이 결과 JSON에 남고 대기열 API가 그 시도의 정확한 자막 `2/3`을 반환하는 것도 확인했다. 실제 ASR·제공자 호출은 없었다. `artifacts/package-v1920.log`.
- 최종 EXE와 실제 PowerShell 도우미로 **1.9.19→1.9.20 인계** 및 의도적 새 실행 실패 시 **1.9.19 복원**을 모두 통과했다(전체 118.80초). 각 시나리오의 연결·분석 결과·SRT·대기열 등 시험 파일 **8개 바이트를 보존**했다. 시험 프로세스만 정리했다. `artifacts/update-handoff-v1920.log`.

운영 프로그램은 확인 시 **1.9.16**으로 실행 중이었다. 실제 사용자 작업을 중지·재실행·재요청하지 않았다. 새 대기열 정책은 화면을 사용하는 PC가 1.9.20으로 실행된 후 적용된다.
