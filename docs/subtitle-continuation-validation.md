# 1.8.2 · 한국어 번역 중단과 부분 자막 보존

## 확인한 결함

원격 번역 전용 복구에서 서버가 더 긴 검수 완료 구간을 만들었어도, 이후 묶음의 실패 상태 때문에 클라이언트가 새 부분 번역을 받지 않고 이전 구간만 유지했다. 예를 들어 80구간을 보관한 결과를 복구하여 160구간까지 검수한 뒤 다음 묶음이 실패하면, 서버 체크포인트는 늘었지만 클라이언트 결과와 SRT는 80구간에 머물 수 있었다.

또한 종료된 작업의 모든 미번역 행을 ‘한국어 번역 대기’로 표시하여 실제로는 번역이 중단된 상태가 계속 진행 중인 것처럼 보였다. 간략한 진행 응답에는 실제 자막 오류도 빠져 있었다.

원래 분석은 완료됐고 한국어 번역만 나중에 추가한 영상에서는, 번역 복구의 부분 결과보다 이전 완료 분석이 화면에서 우선되는 경우도 있었다. 목록에는 원문 본문 대신 원문 지문과 검증된 번역 구간 수를 전달하여, 같은 원문과 요약을 유지한 최신 복구가 다시 열기 후에도 표시되도록 한다. 기존 완성 번역이나 더 긴 검수 구간을 짧은 결과로 교체하지 않는다.

길이 검사는 초안 단계에서 한글·라틴 문자만 세었으므로, 한자 숫자를 정확한 아라비아 숫자로 번역한 경우에도 생략으로 판단할 수 있었다. 정확 모드의 원문 대조 검수에 도달하기 전에 중단되었다. 인명·호칭의 앞뒤 공백 차이만으로 이전 표기와 다르다고 판단하는 문제도 확인했다.

## 보존·완료 규칙

- 실패한 원격 복구에서도 같은 원문·ID·시각·지문·구간 수로 검증된 더 긴 부분 번역은 받아 저장한다. 새 실패 상태와 오류는 유지한다. 기존 완성 자막이나 더 긴 부분 번역을 짧게 교체하지 않는다.
- ‘남은 한국어 자막 번역 계속’은 저장된 원문을 사용한다. 전체 음성 인식, 장면 추출, 줄거리 생성을 실행하지 않는다. 완료 표시는 모든 보관 원문 구간의 번역 검증 후에만 허용한다.
- 번역 완료와 원문 음성의 미확인 구간은 별도로 표시한다. 원문 검수가 남아 있으면 번역을 모두 마쳐도 부분 SRT로 보관할 수 있다.
- 중단된 미번역 행에는 복구가 필요함을 표시하고 구간 수·마지막 번역 시각·오류를 함께 안내한다. 실제 번역 작업이 실행 중일 때만 진행 중으로 표시한다.

## 길이 검사와 이어 처리

숫자와 호환 문자도 정규화하여 길이를 계산한다. 정확 모드에서 짧음으로 의심된 초안에는 원문 대조 검수 기회를 주고, 최종 결과의 구간 수·번호·한국어 형식·시각·길이와 인명 표기를 검사한다. 원문보다 짧은 초안이라고 즉시 미검수 결과를 저장하지 않는다.

큰 묶음의 최종 검수에서도 길이 검사만 실패하면 정확 모드의 해당 작업에서 한 번에 한해 최대 네 개의 20구간 묶음으로 다시 번역·검수한다. 추가 호출은 최대 8회이며 작은 묶음도 검증을 통과한 순서대로만 저장한다. 다시 실패한 작은 묶음을 계속 분할하거나 반복 요청하지 않는다. 제공자 거절·사용량 제한·인증·서비스·연결 오류와 다른 형식 검증 오류에는 이 경로를 적용하지 않는다. 명백한 작업 거절 응답도 번역 길이 문제로 바꿔 처리하지 않는다.

번역 검증 버전은 4로 기록한다. 버전 3의 검수 완료 앞부분은 같은 원문 지문·프로필·검수 횟수·대사 ID·시간·대상 언어와 현재 검증을 모두 통과할 때만 이어 사용하고 버전 4로 보관한다. 검수되지 않은 결과와 다른 원문·품질 설정의 기록은 이관하지 않는다. 인명·호칭은 유니코드 정규화와 앞뒤 공백 제거 후 일치 여부를 판단한다.

## 검증 범위

일반 열차 안내로 만든 합성 원문, 독립 폴더와 모의 Codex 응답만 사용한다. 실제 사용자 영상·대사·이미지를 열거나 번역하지 않는다. 운영 서버에서는 해당 작업의 상태·구간 수·시간·정해진 기술 오류 종류만 확인하며, 요약·대사·이미지 본문을 출력하거나 해석하지 않는다. 서버를 중지·재시작하지 않는다.

서비스 → 원격 엔진 → LAN → 모의 번역 제공자 → 실제 부분 SRT 저장을 연결한다. 첫 시도에서 80개, 다음 시도에서 160개, 마지막 시도에서 161개를 검수하도록 하며 각 복구가 남은 구간부터 시작하는지 확인한다. 실패 후 늘어난 부분 결과, 새 오류, 기존 완성 SRT·원문·요약·시간·이전 기록의 보존을 검사한다.
