# 1.9.4 · 분석 단계의 대기 줄이기

2026-10-18. 인식 모델과 전체 음성 범위, 시간 정렬, 누락 검수 및 한국어 최종 검수 기준을 유지하면서 서로 독립적인 작업을 겹치고 중복 검색을 줄인다. 실제 사용자 영상·대사·이미지를 열거나 외부 AI·GPU 추론을 실행하지 않는다. 운영 서버의 실행·업데이트 상태를 바꾸지 않는다.

## 한국어 번역 초안과 검수의 파이프라인

정확 모드의 원문 480구간 이상인 번역에서 현재 묶음의 최종 검수와 다음 묶음의 초안 요청 한 개를 겹친다. 초안과 검수 자체를 합치거나 검수 횟수를 줄이지 않는다. 최종 검수와 저장은 원문 순서대로 진행하며, 최종 검수에는 직전 묶음까지 보관한 최신 번역과 확정 용어를 전달한다. 먼저 준비한 초안의 번역 문맥은 한 묶음 이전일 수 있으므로, 초안의 문자열이 기존 직렬 실행과 같다고 주장하지 않는다.

첫 묶음과 복구·교정이 필요한 경로는 순차 처리한다. 미리 준비하는 것은 정상 초안 요청 한 개뿐이며 누락 보완을 미리 요청하거나 초안을 체크포인트에 저장하지 않는다. 미리 받은 초안을 요청 당시의 용어로 검사하고, 사용할 때 최신 확정 용어로 다시 검사한다. 그 사이 새로 확정된 용어 때문에 충돌한 경우에만 최신 문맥으로 초안을 한 번 다시 작성한다. 기존부터 있던 용어 충돌, 잘못된 형식, 제공자 거절·인증·사용량·서비스 오류는 이 경로로 재요청하지 않는다.

부모 취소·첫 실패·길이 교정 경로에 들어갈 때에는 앞서 시작한 작업을 취소·정리한다. 실패를 관측한 뒤 새 요청을 시작하지 않으며, 종료 전에 시작한 모든 자식과 임시 파일 정리를 마친다. 진단에는 미리 요청한 초안이 검수·저장된 것처럼 기록하지 않는다. 누락 보완의 작업당 64회 상한은 유지한다.

번역 검증 버전은 6이다. 원문 지문·번호·ID·시각·품질·검수 횟수·한국어 본문·용어를 엄격하게 다시 검사한 버전 3·4·5의 연속된 번역 앞부분은 이어 사용한다. 비교·진단을 위해 `VIDEORANDOM_TRANSLATION_PIPELINE=off`로 번역을 직렬 처리할 수 있다.

## 긴 대사의 구간 요약

긴 원문을 나눈 구간은 서로의 결과나 번역 용어에 의존하지 않으므로 최대 두 요청을 함께 처리한다. 기존 프롬프트·스키마와 구간 분할은 유지하며, 완료 순서와 관계없이 원래 구간 번호로 다시 합친다. 한 깊이의 모든 구간을 마쳐야 다음 요약 깊이로 넘어간다. 최종 영상 요약은 구간 요약 완료 뒤 한 번 실행한다.

첫 오류가 관측되면 미시작 요청을 중단하고 진행 중인 형제 요청을 취소한다. 시작한 모든 자식과 임시 파일 정리를 기다린 뒤 최초 오류를 전달한다. 제공자 거절·인증·사용량·서비스 오류를 자동 재요청하지 않는다. 부모 취소 신호도 같은 정리 경계를 통과하며 신호 리스너를 제거한다.

## 대표 이미지 추출

기존과 같은 자동 균등 시점과 장수·출력 이름·해상도·FFmpeg 인수로 최대 두 장을 함께 추출한다. 결과와 경고는 원래 시점 순서로 보관한다. 개별 장면 실패는 기존처럼 해당 장면의 경고로 남기며 다른 장면을 계속 처리한다.

각 작업의 고유한 임시 JPEG로 추출하고 성공 종료·크기 확인 뒤 최종 이름으로 게시한다. 취소·실패로 남은 임시 이미지는 정리하고 완료된 장면은 보존한다. 취소 후에는 새 장면을 시작하지 않으며 이미 시작한 자식 프로세스의 종료를 기다린다. 두 개의 동시 탐색이 실제 디스크에서 항상 더 빠르다는 보장은 없으므로 인식 단계 전체의 속도 수치로 해석하지 않는다.

## 음성 검수의 CPU 검색

발화와 인식 범위의 차집합은 정렬된 범위의 검색 위치를 재사용한다. 인접 창의 중복 대사 비교는 창별로 보관한 관측만 검색한다. 높은 신뢰도의 대사는 삭제 후보가 아니므로 비음성 여부를 찾기 위한 전체 발화 검색을 생략한다.

기존 1.9.3 함수와 합성 범위·대사·단어 경계를 대조한다. 임의 순서의 입력, 겹침·접점·비연속 창, 암묵적 창 번호와 명시적 0의 차이, 같은 비음성 검사 호출 구간과 입력 불변성을 포함한다. 모델·beam·워커 수·신뢰도 기준·단어 시각·발화 검출·전체 범위와 재검수 예산은 변경하지 않는다.

## 측정 경계

요약·장면 추출의 고정 지연 시험은 요청을 겹칠 때 대기하는 순서와 동시 작업 수를 검증한다. 실제 모델 속도를 측정한 값이 아니다. CPU 검수 측정은 합성 자막 메타데이터의 세 함수에만 해당한다. 음성 인식·외부 번역의 전체 소요 시간이나 인식률이 몇 배 개선됐다는 근거로 사용하지 않는다.

Windows EXE 1.9.0 이상은 내장 업데이트로 받을 수 있다. BAT로 실행한 Node 서버는 새 코드로 다시 실행해야 하며, 실행 중인 작업은 시작한 버전으로 계속 처리한다. 연결 설정·결과·자막과 사용자가 중지한 대기열을 보존한다.

## 검증 결과

- 전체 Node 회귀: `node --test --test-concurrency=4 --test-timeout=60000 test/*.test.js`, **805개 통과, 실패·취소·건너뛰기 0개**, 약 53.0초. 기존 Python ASR·벤치마크 검사와 새 메타데이터 동등성 검사 7개를 포함한다. 새 무작위 대조는 범위 1,200개·창 700개·비음성 정리 700개다.
- 요약 11개와 번역 파이프라인 26개 회귀로 최대 동시 실행, 원문 전체와 순서, 최신 번역 문맥·용어, 신규 용어로 인한 한 차례 초안 교체, 기존 용어 충돌의 중단, 누락·길이 보완, 버전 5 체크포인트 이관, 부분 결과 보존을 검사했다. 제공자 오류를 관측한 뒤 자식 종료나 임시 폴더 삭제가 지연돼도 다음 요청이 시작되지 않는 경합을 별도 게이트로 검사했다.
- 신규 이미지 병렬 회귀 5개와 기존 추출 회귀를 통과했다. 독립적으로 시작한 테스트 자식 두 개의 실제 취소·종료·임시 파일 정리도 확인했다.

운영 분석 서버는 이 검증에서 중지하거나 재시작하지 않았다. 실제 사용자 영상의 번역 완료나 전체 분석 시간·원문 인식률 향상을 측정한 보고서가 아니다.
