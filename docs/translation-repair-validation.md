# 1.8.0 · 한국어 번역만 복구와 속도 우선 설정

## 사용자 동작

- 영상 목록과 상세 화면의 **한국어 자막 번역만 복구**는 저장된 원문 대사와 시작·종료 시각을 사용한다. 음성 인식, 장면 추출, 줄거리 생성을 실행하지 않는다. 원문이 없거나 원본 파일이 변경되었으면 전체 분석을 먼저 안내한다.
- 복구 결과는 별도 기록으로 저장한다. 원래 요약·이미지·원문·분석 소요 시간·분석 버전을 보존하고, 번역 복구 시간과 사용한 프로그램/서버 버전을 별도로 기록한다. 번역 실패 시 기존의 유효한 자막과 더 긴 부분 번역을 보존한다.
- 한국어 전체 자막 또는 검증된 부분 자막은 기존 파일 보존 규칙에 따라 영상 폴더에 저장한다. 미완료 원문을 번역했다고 음성 누락 검수가 완료되었다고 표시하지 않는다. 부분 자막은 `.ko.partial.srt`로 구분한다.
- 새 서버는 전체 분석 한 건과 번역 전용 한 건을 별도 처리할 수 있다. 전체 음성 분석의 동시 실행 수는 늘리지 않는다. 구버전 서버가 번역 전용 기능을 지원하지 않으면 업데이트를 안내하며 전체 분석으로 대체하지 않는다.

## 속도 설정과 적용 범위

새 설정의 기본값은 속도 우선이다. 기존에 명시적으로 저장한 정확도 우선 선택은 유지한다. **분석 설정 → 속도 우선으로 설정**을 누르면 빠른 프로필을 저장하고 기존 자막이 있어도 전체 음성을 다시 인식하는 옵션을 해제한다. 서버 연결·언어·이미지 수·한국어 번역 선택은 유지한다.

속도 우선은 기존 자막을 먼저 사용한다. 음성 인식이 필요하면 `small` 모델과 사용 가능한 GPU를 선택하며 CPU/계산 형식의 명시적 환경 설정은 존중한다. 문장 단위의 실제 구간 시각을 사용하고 단어별 정렬과 발화 누락 재검수를 생략한다. `large-v3`와 전체 음성 누락 재검수를 사용하는 정확도 우선보다 원어 인식과 세부 시각이 부정확할 수 있다. 정확도 우선의 인식 설정은 유지한다.

클라이언트와 분석 서버 모두 새 버전으로 실행해야 원격 기능이 적용된다. 이미 실행 중인 분석에는 소급 적용하지 않는다. 기본 데이터 폴더를 그대로 사용하면 저장된 결과와 서버 연결 설정을 유지한다.

## 검증

합성 열차 안내 원문과 독립 테스트 폴더만 사용한다. 실제 사용자 영상·대사·이미지를 검사하지 않았으며 운영 서버와 GPU 추론 작업을 중단하거나 새 추론을 겹쳐 실행하지 않았다.

- 공급자 모의 프로세스 검사: 번역 초안/검수만 호출하고 음성 도구·영상 추출·요약을 호출하지 않는다. 정확한 체크포인트 재사용, 명시적 재번역, 실패·취소 보존, 한국어 원문 처리, 잘못된 시각 거절을 검사한다.
- 서비스 → 원격 엔진 → LAN → 모의 번역 공급자 → 실제 SRT 자동 저장을 연결한다. 원문 ID와 밀리초 시각, 기존 분석 정보, 신규 번역 버전, 이미지 보존을 확인한다. 번역 전용 업로드에는 이미지·음성이 없다.
- LAN의 별도 처리 한도, 구버전 거절, 잘못된 반환 자막, 기존 실패 원인 보존, 미검수 원문과 번역 완료의 구분을 검사한다.
- 브라우저에서 번역 복구 진행/완료, 원래 분석 버전과 번역 복구 버전, SRT 저장 안내, 좁은 화면의 버튼 배치, 속도 우선 전환을 확인한다. 화면 예시는 실제 영상 결과가 아닌 합성 자료다.

실제 GPU 음성 인식의 비교 소요시간과 인식률은 이번 검증에서 측정하지 않았다. 긴 영상의 1~2분 완료나 특정 배수의 속도 향상을 보장하지 않는다. 1.7.1의 같은 모델 병렬 처리 검증은 [음성 인식 처리 개선](asr-performance-validation.md)에 정리했다.

예전 결과에 분석 버전이나 완료 소요시간이 없으면 파일 수정 시각이나 현재 실행 버전으로 추정해 채우지 않는다. 새로 기록하는 버전은 해당 작업을 실제로 수행한 프로그램과 현재 연결한 서버의 응답에서 가져온다. 번역만 복구해도 알 수 없는 원래 분석 버전은 그대로 미상으로 남긴다.
