# 1.9.13 · 영상별 한국어 자막 완료 / 전체 구간 표시

2026-10-20. 실제 사용자 영상·음성·대사·이미지·제공자를 사용하지 않고 합성 자료로 검증했다. 운영 서버·저장된 결과·대기열·연결 설정은 변경하지 않는다.

## 변경

- 기존 대사 요약 열에 자막 수를 독립 표시한다. 예: **한국어 자막 · 미완료 / 200 / 2,000구간 / 미번역 1,800구간**, 진행 막대와 **남은 1,800구간 번역 복구** 버튼.
- 줄거리나 `status=completed`에 가려지지 않도록 검증한 저장 자막 수로 판정한다. V1 연속 부분과 V2의 중간 구멍 뒤 구간을 모두 정확히 센다. 개수만 있거나 지문·ID·시각이 불일치한 대사를 승인된 자막으로 올리지 않는다.
- `자막 미완료 N개`를 누르면 저장된 모든 영상 표시를 켜고 검색을 초기화해 미완료 필터를 적용한다. 현재 40개 페이지에 한정하지 않으며 다음 페이지로 남은 영상을 확인한다. 상태 선택에서도 같은 필터를 제공한다.
- N/N이면서 최종 검수가 미완료인 경우도 미완료로 남긴다. N/N 번역 완료의 원어 확인·파일 저장 실패와 원어 전용 0/N 번역 전은 실제 미번역과 구분한다. 이전 완성 자막을 보존한 뒤 새 대체 시도만 실패한 경우를 다시 미번역으로 세지 않는다.
- 백엔드 파생 필드 `subtitleTranslationAttempted`, `subtitleTranslationComplete`, `subtitlePendingCount`를 추가했다. 기존 count·원문 지문과 `health.completion`의 엄격한 계산을 공유하며 API 조회는 기존 결과 파일을 다시 쓰지 않는다.
- 동일 원문과 저장 시각을 가진 오래된 응답이 높은 번역 개수를 낮추거나 최신 상태를 가리지 않게 한다. 같은 기록의 같은 구간 수 새로고침은 전체 대사 객체와 부분 자막 검증을 보존한다. 더 새로운 원문 변경이나 실제 수정에 따른 개수 감소는 허용한다.
- 번역 복구는 기존 명시적 `/subtitles/repair`를 호출한다. 목록 조회·필터는 자동 재시도를 시작하지 않는다. 다른 작업이 진행 중이거나 로컬 로그인 환경을 사용할 수 없으면 버튼을 막는다. 원문 번역 복구에 음성 인식 도구를 요구하지 않는다.
