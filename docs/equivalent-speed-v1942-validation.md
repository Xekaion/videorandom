# 1.9.42 · 동일한 작업의 중복 계산 감소

2026-11-18. 기준은 v1.9.41이다. 실제 영상·음성·대사·요약·제공자 출력이나 운영 로그를 열지 않고 중립 자막, 수치 메타데이터와 모의 CLI로 비교했다. 실제 ASR·GPU 추론·번역 요청과 운영 프로그램 종료·교체는 하지 않았다.

## 유지한 작업

ASR 모델·beam·VAD와 독립 음향·앞부분 누락 검사·재인식 범위, 번역 초안과 독립 원문 검수, 구간 번호·시간·문맥·용어·거절 검사와 모든 제공자 요청 수를 유지한다. 인식 revision과 번역 프롬프트·체크포인트 형식도 유지해 기존 검증된 결과를 다시 처리하게 만들지 않는다.

## 변경

- 검증된 원문 번호를 정렬된 인덱스에 유지한다. 문맥의 직전 8개를 이진 검색으로 찾고, 기존 Map 순회·새 정렬 스냅샷·드문 빈 구간 삽입 의미를 보존한다.
- 콘텐츠 체크포인트의 전역 직렬 쓰기 안에서 기존처럼 디스크 바이트를 읽는다. 같은 작업이 마지막으로 정상 저장한 바이트와 정확히 같을 때만 그때의 자막 검증 증거를 재사용한다. 수정·삭제·다른 작성자의 내용이면 기존 전체 검증으로 돌아가고 다른 확정 표현을 덮지 않는다. 기록 파일과 콘텐츠 인덱스의 모든 쓰기·최종 완료 경계는 유지한다.
- 진단 조회의 시간/ID 순서·PC 목록·통계·커서를 실제 저장 변경 뒤 한 번 구성한다. 그대로인 UI 조회는 필요한 페이지와 추가 한 행만 찾는다. 필터·내보내기 순서·조회 중 새 저장·실패한 저장과 복구 표시를 보존한다. 반환 자료는 독립 투영이므로 화면이 결과를 수정해도 캐시가 변하지 않는다.
- 음성 신뢰도 판정에서 이미 계산한 단어별 평균을 같은 호출 안에서 재사용한다. 변경 가능한 cue에 대한 영구 캐시는 만들지 않는다.
