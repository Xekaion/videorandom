# 1.9.6 번역 거절 판정 진단 검증

## 확인한 코드 문제

이전 `SUBTITLE_PROVIDER_REFUSAL`은 `validateBatchResult()`에서 두 경우에 사용됐다. 반환 JSON의 `refusal` 속성이 참인 경우와 자막 본문이 `explicitTranslationRefusal()`의 작업 거절 문구에 일치하는 경우다. 이 코드만으로 실제 외부 서비스의 정책 거절 이벤트라고 확정할 수 없다. 기존 기록에는 어느 조건인지 저장하지 않았다. 구체적인 거절 사유나 원 응답 본문도 저장하지 않아 과거 원인을 소급해서 복원할 수 없다.

문구 감지는 계속 중단 조건으로 유지한다. 일반적인 대사와 일치할 가능성이 있다는 이유로 검증을 해제하거나, 거절된 묶음을 잘게 나누거나, 초안을 최종 자막으로 저장하지 않는다. 실제 거절인지 오탐인지 확인하지 못한 사용자 영상을 재요청하지 않는다.

별도로 오류 분류의 `/refus/`가 네트워크 오류 `ECONNREFUSED`에도 일치하던 문제를 확인했다. 진단 분류에서 명확한 인증·사용량·503·시간 초과·시스템 연결·저장 오류를 먼저 식별한다. 이 변경은 진단 분류에만 적용하며 분석 요청 재시도 정책은 바꾸지 않는다.

## 새 진단 계약

| 발생 조건 | 코드 | refusalSource |
| --- | --- | --- |
| 반환 JSON에 거절 표시 | `SUBTITLE_PROVIDER_REFUSAL` | `response-field` |
| 자막 본문에 작업 거절 문구 감지 | `SUBTITLE_REFUSAL_TEXT_DETECTED` | `subtitle-text` |
| 분석 도구 실행 실패에서 거절 표시 감지 | `PROVIDER_REFUSAL` | `execution-error` |
| 이전 기록에 근거 없음 | 기존 코드 유지 | 미기록 |

`refusalSource`는 위 세 문자열만 허용하고 거절 관련 코드에만 보존한다. 원문, 번역문, 이미지, 프롬프트, 응답 본문, 임의의 거절 사유, 경로와 인증 정보는 새 진단에 추가하지 않는다. 특정 정책 카테고리나 파일명에 근거해 거절 사유를 추정하지 않는다. 표시하는 구간 번호와 요청·반환 개수는 수치 검증을 거친다.

공통 진단 정제를 통해 저장소·서버 보고·LAN 반환·재시작·JSONL 내보내기에 출처를 보존한다. 가벼운 영상 목록과 작업 조회에도 정제한 `subtitleDiagnostic`을 포함한다. UI는 출처 설명과 구체적인 거절 사유 미기록을 표시한다. 출처가 없으면 이전 버전의 판정 근거 미기록으로 안내하고 코드 이름만으로 출처를 채우지 않는다. 부분 완료 안내에서 일반적인 재시도 성공 약속도 제거한다.

## 보존하는 동작

음성 인식 모델·전체 처리 범위·자막 시각·신뢰도·초안·최종 검수·최종 순차 저장·누락 보완과 길이 교정 예산은 바꾸지 않는다. 거절 감지는 대사 개수·길이 교정보다 먼저 중단한다. 원문과 기존 검수된 앞부분은 유지하며 거절 문구를 자막으로 채택하지 않는다. 번역 수용 기준과 프롬프트가 같으므로 번역 체크포인트 버전은 6을 유지한다.

이번 수정으로 기존 사용자 영상의 번역이 끝났다는 의미는 아니다. 실제 거절 또는 문구 감지를 제거해 완성을 보장하는 기능도 아니다. 현재 확인 가능한 기술 메타데이터와 그 한계를 정확히 표시한다.

## 검증 범위

합성 1,819구간 중 240구간을 미리 저장한 사례로 초안/검수 각각에 반환 거절 표시와 자막 문구 감지를 주입한다. 실패한 묶음의 구간·요청/반환 수와 출처를 확인하고, 추가 요청이 없으며 기존 240구간의 ID·시각·텍스트·체크포인트 바이트가 동일한지 검증한다. 일반적인 도움 거부 대사의 허용 검사와 명시적 거절의 중단 검사를 함께 유지한다.

진단 검사는 임의 출처·원문·응답 본문 정제, 재시작·보고·내보내기 보존, 네트워크/인증/사용량 오류 구분을 확인한다. LAN 가짜 처리기는 출처를 반환한 뒤 재실행해 저장된 최종 상태만 읽고 번역을 다시 호출하지 않는지 검사한다. UI는 합성 데이터로 출처별 설명·구버전 미기록·단순 네트워크 오류를 검증한다. 실제 사용자 영상·음성·이미지·원문·서비스 응답 본문을 열람하거나 외부 AI 또는 GPU를 호출하지 않는다.
