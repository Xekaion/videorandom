# 1.9.8 · 자막 중복 작업과 대기 줄이기

2026-10-19. 정확 모드의 모델·beam·연산 형식·워커 선택·전체 음성 처리·단어 시각·발화 검출·누락 재검수·신뢰도 기준·번역 검수 횟수는 유지한다. 사용자 영상·대사·이미지나 실제 AI·GPU 추론은 이 검증에서 사용하지 않는다. 운영 분석 서버는 중지하거나 교체하지 않는다.

## 변경 범위

영상 목록의 `.catalog-label`은 10px에서 8px로, 안쪽 여백은 3px 7px에서 2px 5px로 줄인다. 기존 목록 배치와 그 밖의 본문 글자 크기는 유지한다.

음성 재검수에서 고정된 대상 구간을 한 번 정렬·색인하고, 대사·단어마다 전체 대상을 다시 훑지 않는다. 독립 재인식 후보는 적격성과 중간 시각으로 검색하며, 실제 선택 순서는 이전 후보 순서를 유지한다. 이웃 자막은 보수적인 시간 범위 트리로 검색하고, 재검수 결과가 원래 구간 밖으로 확장되면 해당 경계를 갱신한다. 마지막 겹침 판정의 0.02초, 단어 교차 판정의 0.001초와 실제 원문·시각은 이전과 같다.

번역은 기존 정확 모드의 다음 초안 한 개 선행 준비를 480구간 이상에서 320구간 이상으로 확장한다. 첫 묶음의 검수와 내구 저장이 성공한 뒤에만 시작한다. 최종 검수·최신 확정 용어·순차 저장·캐시 버전 6·요청 크기·최대 동시 두 요청·제공자 거절 시 즉시 중단은 유지한다. 480구간 이상의 파이프라인은 기존 기능이므로 이번 추가 가속 범위로 계산하지 않는다.

LAN 서버는 처리 후 실제 결과 이미지의 SHA-256을 선택적 기능으로 광고한다. 요청 PC는 검증된 원래 프레임 이름에 대해서만 로컬 JPEG의 해시와 대조하고, 정확히 같을 때 재다운로드와 덮어쓰기를 생략한다. 해시가 없거나 잘못됐거나 구서버면 기존 전송 경로를 사용한다. 파일 읽기는 크기 상한·파일 핸들·변경 확인·취소를 적용한다. 다운로드가 필요하면 받은 바이트도 광고된 해시와 대조한다. 불일치 시 재요청 없이 오류를 남기고 기존 이미지와 받은 분석 텍스트를 보존한다. 선택적 해시 검사 중 취소해도 이미 생성한 대사·요약을 취소 상태의 복구 기록으로 보존한다. 서버 주소·연결 코드·기존 결과·부분 자막은 별도로 변경하지 않는다.

## 합성 측정

다음 수치는 부분 기능의 측정이며 실제 영상 완료 시간의 보장이나 인식률 개선의 근거가 아니다.

| 측정 범위 | 기존 | 변경 후 | 조건 |
| --- | ---: | ---: | --- |
| 재검수 대상 검색 + 대조, 1,819구간 | 6.453초 | 0.064초 | 이전 코드와 출력 동일, CPU 메타데이터만 |
| 재검수 대상 검색 + 대조, 6,000구간 | 68.316초 | 0.210초 | 이전 코드와 출력 동일, CPU 메타데이터만 |
| 정확 번역 320구간 | 263.2ms | 201.1ms | 요청당 모의 15ms, 8회 동일 |
| 정확 번역 479구간 | 398.9ms | 262.8ms | 요청당 모의 15ms, 12회 동일 |
| 이미지 10장 반환 | 평균 1,572ms | 평균 21ms | 장당 128KiB·모의 지연 150ms, 이미지 GET 10→0회, 3회 평균 |

재검수 CPU 측정은 `python -B test/test_asr_recovery_performance.py --benchmark`로 재현한다. 번역은 `node --test --test-name-pattern='synthetic' test/translation-speed-v198.test.js`로 모의 비교한다. 고정 지연 요청의 초안과 최종 출력은 합성 응답이므로 실제 모델의 문맥 차이나 번역 시간을 측정하지 않는다. 이미지 비교는 로컬 HTTP 모의 서버이며 실제 Wi-Fi 성능이 아니다.

이미 1.9.7에서 파이프라인을 사용하던 1,819구간 번역은 이번 변경만으로 더 빨라졌다고 주장하지 않는다. GPU 음성 디코딩이나 제공자의 응답 대기 시간이 대부분인 영상에서는 위 계산 최적화만으로 큰 전체 시간 단축이 보장되지 않는다. 이미 시작한 작업에 새 함수가 중간 삽입되지 않으며, 새 버전으로 시작한 작업부터 적용된다.

## 검증

신규 Python 회귀 7개는 무작위 대상·후보·동일 시각의 안정 정렬·경계 교차·이웃 교체와 구간 확장·빈 대체를 이전 함수와 대조한다. 기존 ASR 99개와 구간 성능 검사 7개도 유지한다. Node 테스트가 신규 Python 검사를 함께 실행한다.

번역 회귀는 320·400·479구간 전체 번호·시각·검수·저장, 첫 검수 실패, 인증·사용량·서비스 오류, 자식 취소·정리, 신규 용어 충돌의 제한적 교체와 캐시 재사용을 검사한다. LAN 회귀는 정확한 로컬 이미지 재사용, 변경·누락·손상·구서버·잘못된 해시/경로·403 중단·터미널 저널 복구를 합성 파일로 검사한다. 브라우저에서는 합성 목록의 라벨 10개 모두 8px이고 오류 로그가 없음을 확인했다.

- 전체 회귀: `node --test --test-concurrency=4 --test-timeout=60000 test/*.test.js`, **899개 통과**, 실패·취소·건너뛰기 0개, 약 56.3초. 첫 실행에서 기존 이미지 인계 시험이 새 재사용 경로로 다운로드를 생략해 대기했으므로, 업로드 후 합성 클라이언트 사본만 제거해 실제 이미지 복구가 필요한 상황을 명시했다. 해당 시험과 최종 전체 회귀가 통과했다.
- Windows EXE: **99,424,349바이트**, SHA-256 `508696996357be846589c5a2fd45006b5c8237360f9caf9cf2b58338adf70fbb`. 버전 고정 업데이트 주소·파일 크기·해시·MZ 헤더를 대조한다.
- 최종 EXE를 독립 저장소·사용하지 않는 포트에서 실행해 웹 자산 일치, 목록·상세·진단, 번역만 복구, 구간 진행률·예상 시간, 원래 ID·시각과 영상 옆 한국어 SRT, 기존 완성 자막·중지 대기열·기록 보존을 확인했다. 인식·실제 제공자 호출은 하지 않았다.
- 복사한 실제 **1.9.7→1.9.8 EXE** 업데이트 인계에서 같은 테스트 포트·저장소로 활성화됐고, 결과·자막·대기열·암호화한 연결 설정·진단 등 **8개 파일이 바이트 단위로 유지**됐다. 이 검증이 직접 만든 프로세스와 저장소만 사용하고 정리했다.

운영 서버의 기존 실행은 유지했다. 이 릴리스는 기존 사용자 영상의 번역을 완료했다거나 전체 분석 시간을 실제 측정했다는 보고가 아니다. 인식·번역 개선은 해당 처리를 수행하는 PC에 새 실행 파일이 적용된 이후의 작업부터 사용한다. 이미지 재전송 생략은 서버와 요청 PC 모두 새 기능을 지원해야 사용한다.
