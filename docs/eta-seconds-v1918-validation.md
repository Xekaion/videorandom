# 1.9.18 · 초 단위 단일 예상 잔여시간

2026-10-21. 변경과 검증에는 소스 코드·중립 합성 진행 정보·별도 시험 저장소만 사용한다. 운영 서버·작업·설정·결과를 변경하거나 실제 사용자 미디어·대사·요약을 읽지 않는다. 실제 모델·번역 제공자를 호출하지 않는다.

## 변경 범위

- `remainingSeconds` 하나를 `약 12분 34초`, `약 1시간 02분 03초`, `약 18초`로 표시한다. 초의 소수 부분만 올림하며 분 단위 올림을 제거한다. 진행 중에는 0초 입력도 약 1초로 표시하고 완료 상태는 기존 작업 상태 표시를 사용한다.
- 음성 인식·재검수·번역·요약의 공통 진행 안내와 분석 현황의 대체 표시를 같은 형식으로 맞췄다. 최소·최대 메타데이터는 이전 서버·저장 형식과의 호환성을 위해 유지하지만 화면에 범위로 표시하지 않는다.
- 단위는 초까지 보여도 예측의 정확도가 초 단위로 보장되지는 않는다. `약`, `현재 단계 예상 잔여`, 이후 단계 별도 안내를 유지하고 현황 안내에 실제 처리 속도로 보정하는 예상값임을 명시한다. 고정된 카운트다운을 새로 만들지 않는다.
- 처리량·요청 시간 계산, 표본의 누적 경과 시간, 여러 LAN 전달 단계, 120초 초과 표본과 지연된 제공자 요청의 숫자 숨김, 연결 오류·완료 처리와 원문의 저장 개수를 유지한다. 새 타이머·네트워크 요청·재시도·모델 설정 변경은 없다.
- 화면을 사용하는 PC의 변경이다. 이전 서버의 유효한 진행 정보를 새 화면에서도 초까지 표시한다. 서버 처리 속도가 바뀌었다는 변경은 아니다.

- 현황 화면에서 단일 값, 원래 저장 개수·진행률, 검수 응답 지연과 오래된 표본·연결 오류의 수치 숨김을 확인한다. 기존 음성 진행 UI의 기대값도 정확한 초 단위로 변경했다.
