# 1.8.1 · 자막 복구 후 자동 분석 대기

## 문제

자동 분석의 이전 실패나 부분 완료로 저장된 `paused: true`는 새 영상 뽑기와 자막 번역 복구를 거쳐도 유지되었다. 복구가 끝나면 대기 처리를 예약하지만, 남은 일시중지 상태가 다음 영상의 시작을 막았다. 뽑기 화면은 중지 이유 없이 ‘자동 분석 대기 · 일시 중지됨’만 표시하여 이를 구분하기 어려웠다.

복구 자체가 대기를 중지시키는 것은 아니다. 기존 중지가 남을 수도 있고, 이어서 시작한 자동 분석이 실패하여 새로 중지될 수도 있다. 사용자 화면의 짧은 문구만으로 어느 경우인지 단정하지 않는다.

## 변경

- 전체 음성 처리 증거가 있고 요약과 요청한 한국어 번역이 유효하게 끝난 자료는 품질 경고 때문에 부분 완료여도 다음 영상으로 진행한다. 원문 미확인 구간, 부분 자막, 해당 영상의 상태는 보존한다. 실제 실행·요약·번역 오류와 사용자 취소는 이 조건에 해당하지 않는다.
- 중지 원인을 제한된 종류와 필요한 파일·결과 식별 정보로 대기 기록에 보관한다. API에는 원인 종류를 노출한다. 내용·대사·연결 코드를 추가로 저장하지 않는다.
- 같은 실패 결과에 연결된 명시적 복구가 문제를 해결한 경우에만 해당 실패로 생긴 중지를 해제한다. 사용자 취소, 다른 파일의 실패, 해결되지 않은 오류, 검증할 수 없는 예전 중지는 유지한다. 복구의 결과 파일과 재개된 대기 상태를 저장한 뒤 다음 작업을 시작한다.
- 뽑기 화면에 실제 중지 이유와 ‘자동 분석 재개’를 표시한다. 이 버튼은 기존 재개와 같은 요청을 사용하며, 중복 클릭과 설정 로딩을 처리한다. 복구가 진행 중이면 재개 요청 이후에도 복구가 끝날 때까지 다음 분석은 기다린다.

이미 중지된 구버전 기록은 원인을 추정해서 해제하지 않는다. 사용자가 재개를 한 번 누르면 보관된 대기 목록을 계속 처리한다.

## 검증 범위

독립 데이터 폴더, 합성 열차 안내 자막·파일, 모의 분석 엔진과 LAN 번역만 사용한다. 사용자 영상·대사·이미지와 실제 AI 공급자를 사용하지 않는다. 운영 서버나 사용자 프로그램을 중지·재시작하지 않는다.

API 회귀 검사에서는 품질 경고만 있는 부분 완료 이후의 다음 영상 진행, 실제 실패·취소 중지 유지, 같은 실패 결과의 복구 중 새 영상 등록과 복구 후 순차 처리, 관계없는 복구와 예전 중지 유지, 재실행 시 원인 보존과 잘못된 원인 거절을 확인한다. UI 검사에서는 중지 이유·재개 버튼·실패 안내와 복구 중 새 뽑기 이후 명시적 재개를 확인한다.
