# 1.9.11 · 초고속 모드와 검수 중복 출력 줄이기

2026-10-19. 사용자가 속도와 정확도의 교환을 허용해 명시적으로 선택하는 `turbo` 모드를 추가했다. 기존 `fast`·`accurate` 선택, 데이터 폴더·주소·연결 코드·기존 분석·자막·대기열은 자동 변경하지 않는다. 운영 프로세스·실제 사용자 영상·이미지·대사·외부 AI·GPU 추론을 검증에 사용하지 않는다.

## 초고속 경로

기본 모델은 다국어 `turbo`이며 환경변수의 명시 모델 지정은 유지한다. 단일 탐색(beam/best_of 1, temperature 0), `BatchedInferencePipeline`, GPU 배치 4·CPU 배치 1·워커 1을 사용한다. 정확 모드의 음성 모델·인수·누락 재검수·번역 검수 횟수는 바꾸지 않는다. 초고속의 한국어 번역은 1회이며 번호·본문·인명·생략 검사·시간 보존과 오류 중단 규칙은 적용한다.

모든 입력 샘플을 읽는다. 무손실 16kHz 단일 채널 FLAC을 빠른 압축 수준으로 준비하고, 90초 중심 구간에 앞뒤 문맥을 더한다. faster-whisper 1.2.1의 명시 clip은 30초보다 길면 뒤쪽이 잘리므로 각 입력 창을 인접한 30초 이하 clip으로 나눈다. `vad_filter=False`, `without_timestamps=False`로 소리를 검출하지 못했다는 이유로 입력을 건너뛰지 않고 실제 모델의 문장 시각을 사용한다. clip 경계를 자막 시간으로 만들거나 단어 시간을 추정하지 않는다.

한 창의 출력은 디코더가 끝난 후 반영한다. GPU 메모리 부족만 현재 창을 배치 1로 한 번 다시 처리하며 이후에도 1을 유지한다. 이전 창은 다시 인식하지 않는다. 다른 오류와 작은 배치의 실패는 즉시 중단한다. 배치 API가 없으면 준비 필요를 알리고 기존 경로를 초고속으로 표시하지 않는다.

전체 창의 생성기를 소비한 뒤에만 `processingComplete=true`와 실제 처리 길이를 기록한다. 초고속은 단어 정렬과 독립 누락 검수를 생략하므로 `wordTimestamps=false`, `audit.complete=false`다. 이 모드의 완료는 선택한 처리 범위를 끝냈다는 뜻이며 정확 모드의 검수 증거로 사용할 수 없다. 캐시는 품질과 전체 처리 증거가 같은 경우만 재사용한다. 바뀐 원본의 크기·수정 시각을 확인하면 기존 추출을 다시 사용하지 않는다.

LAN은 `turbo-subtitles-v1`을 광고한다. 요청 PC는 구서버에 실제 추출·업로드를 시작하기 전에 업데이트를 안내하며 품질을 자동으로 바꾸지 않는다. 전체 FLAC 또는 완료된 같은 모드의 원문 증거가 필요하고 MP3는 이 경로에서 거절한다. 실제 모델·장치·배치 크기는 진행률과 결과·기술 기록으로 전달한다. 임의 경로·모델 명령·연결 정보는 새 필드에 포함하지 않는다.

## 정확 모드의 검수 응답

초안과 모든 cue의 독립 원문 대조는 유지한다. 검수 응답을 `approvedIndexes`·`corrections`·`terms`로 받는다. 원문 번호가 명시 승인된 경우에만 초안 문장을 사용하고, 수정 번호는 반환된 최종 문장으로 바꾼다. 누락 번호를 자동 승인하지 않는다. 중복·범위 밖 번호·승인과 수정 교차·알 수 없는 필드·잘못된 본문은 중단한다.

복원한 전체 문장은 기존 한국어·길이/생략·거절·필수 인명과 표기 검사에 그대로 통과해야 한다. 짧은 초안을 명시 승인해도 최종 길이 검사를 우회하지 못한다. 검증 가능한 부분 응답의 누락은 기존 20개·작업당 추가 64회 상한으로 보완한다. 거절·인증·사용량·503·시간 초과·연결 오류는 재요청하지 않는다. 검증된 연속 앞부분만 먼저 저장하고 취소된 선행 요청을 모두 정리한다.

응답 프로토콜·프롬프트 버전은 7이다. v6·v5·v4·v3의 검증된 체크포인트는 원문 지문·번호·ID·시각·품질·검수 횟수·본문·인명을 다시 검사해 이어 사용한다. 구형 응답의 전체 문장 형식도 동일한 최종 검증기로 처리한다.

## 측정 범위

80개의 합성 열차 안내 대사를 사용한 JSON 바이트 비교다. 실제 제공자·출력 토큰·벽시계 처리시간·음성 인식률 측정이 아니다.

| 수정 cue | 이전 전체 재출력 | 새 승인·수정 응답 |
| ---: | ---: | ---: |
| 0 | 12,256 B | 279 B |
| 1 | 12,256 B | 428 B |
| 8 | 12,256 B | 1,478 B |
| 40 | 12,256 B | 6,278 B |
| 80 | 12,256 B | 12,279 B |

초안·검수 입력과 의미 대조 계산, 제공자 왕복, 음성 디코딩 비용은 남는다. 이미 다음 초안을 선행 준비하던 영상에서는 검수 응답을 줄인 만큼 전체 시간이 같은 비율로 감소하지 않는다. **전체 분석 20배 가속을 달성했다고 주장하지 않는다.** 초고속은 정확도 교환을 허용한 별도 선택이며 실제 같은 공개·사용 허가 음성, 같은 장치의 완료 시간·누락·인식 오류·자막 시각을 비교해야 가속 배수를 알 수 있다.

모델과 배치 API의 선택 근거는 [Whisper 공식 모델 설명](https://github.com/openai/whisper#available-models-and-languages), [faster-whisper 공식 배치 사용법](https://github.com/SYSTRAN/faster-whisper#batched-transcription), [사용 중인 1.2.1 구현](https://github.com/SYSTRAN/faster-whisper/blob/v1.2.1/faster_whisper/transcribe.py)이다. 개발자가 다른 장치와 자료로 발표한 속도를 이 PC의 완료 시간에 그대로 적용하지 않는다.

## 검증

- 전체 회귀: `node --test --test-concurrency=4 --test-timeout=60000 test/*.test.js`, **1,029개 통과**, 실패·취소·건너뛰기 0개, 약 69.9초.
- 신규 합성 Python 17개는 2시간 입력의 전체 sample·30초 clip 경계, 실제 시각, 배치 상한, CPU·OOM 한 번 복구·다른 오류 중단·모델 지정·기존 경로 격리를 검사한다. 실제 모델이나 GPU는 실행하지 않는다.
- JS 검사는 희소 검수의 승인·수정·누락·짧은 번역·용어·거절·취소·선행 요청 정리·v6 복구, 초고속 설정의 재실행 보존·자동/수동/복구·LAN·구서버 거절·정확 모드와 캐시 격리·실제 배치 메타데이터를 검사한다.
- 전체 검사 후 기존 외부 자막이 있어도 명시한 초고속 모드가 전체 음성 인식을 실행하는 회귀를 추가했다. 해당 파일 8개 모두 통과했으며 모델은 모의 응답이다. 실행 코드 변경은 없었다.
- 독립 합성 브라우저에서 초고속 선택·추가 검수 생략 설명과 실제 선택 표시를 확인했고 브라우저 오류·경고는 없었다. 실제 사용자 설정을 바꾸지 않았다.

최종 Windows EXE는 **99,454,509바이트**, SHA-256 `d39803b67f5cf0d2a9f9f074bbeb496d9bba68afdd617ba69b5f467cb9089aaf`다. 버전 고정 업데이트 주소·바이트 수·실제 해시를 대조했다.

- 독립 저장소·사용하지 않는 포트의 실제 EXE에서 화면 자산, 목록·상세·진단, 부분/완성 자막 보존, 번역 전용 복구·진행률·시간 추정과 영상 옆 SRT 자동 저장을 확인했다. 거절·대기 제한 등 기존 오류 정보도 유지됐다.
- 별도로 복사한 EXE와 합성 LAN 서버에서 초고속 선택·실제 모델/배치 4 기록·전체 3개 한국어 cue와 원래 ID/시간·검수 미수행 표시·영상 옆 SRT를 확인했다. 기존 결과·완성 SRT·중지한 대기열·초고속 설정과 암호화된 연결은 보존됐다. 실제 음성·요약·번역 제공자는 실행하지 않았다.
- 복사한 실제 **1.9.10→1.9.11 EXE** 업데이트가 같은 테스트 포트·저장소로 활성화됐고 결과·자막·대기열·암호화된 연결·진단 등 **8개 파일이 바이트 단위로 유지**됐다. 검사가 직접 만든 프로세스만 신원 확인 후 정리했다.

운영 분석 서버는 중지·교체·설정 변경하지 않았다. 새 처리를 적용하려면 해당 PC에서 새 실행 파일을 실행해야 하며, 이미 진행 중인 작업에는 새 함수가 삽입되지 않는다.
