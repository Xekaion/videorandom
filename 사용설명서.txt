======================================================================
🎬 Video Roulette (영상 랜덤 뽑기 프로그램) - 무설치 실행 가이드
======================================================================

사용자님의 편의를 위해, 별도의 프로그램(Node.js 등)을 전혀 설치하지 않아도 
더블 클릭 한 번으로 실행되는 단일 실행 파일 [videorandom.exe]을 직접 빌드해 두었습니다!

어떤 윈도우 컴퓨터에서든 아래 설명대로 즉시 가동하실 수 있습니다.

----------------------------------------------------------------------
🎮 가장 쉽고 빠른 실행 방법 (추천!)
----------------------------------------------------------------------
1. 이 폴더 안에 있는 [videorandom.exe] 파일 하나만 USB, 메일 등으로 복사해서 
   다른 컴퓨터로 옮깁니다. (따로 압축을 풀거나 다른 설치를 할 필요가 전혀 없습니다.)
2. 옮긴 컴퓨터에서 [videorandom.exe]를 더블 클릭하여 실행합니다.
3. 자동으로 검은색 로더 창이 뜬 후, 크롬이나 엣지 브라우저가 열리며 
   화려한 네온 스타일의 영상 뽑기(Video Roulette) 프로그램이 즉시 실행됩니다!

----------------------------------------------------------------------
💡 사용 팁 & 편의 기능
----------------------------------------------------------------------
* 새 버전 확인: 화면 상단에 버전 번호가 표시됩니다. 구버전이 켜져 있으면 새 버전은 다른 주소에서 열리고 안내를 보여줍니다. 이전 브라우저 기록을 가져오려면 실행 중인 VideoRandom 창들을 종료하고 새 파일을 같은 브라우저의 http://localhost:3000에서 여세요. 필요하면 Ctrl+F5로 새로고침하세요.
* 전체 영상 기록: 스캔 전에도 저장된 뽑기와 재생 실행 기록이 표시됩니다. 같은 영상을 반복해서 뽑아도 각각 남습니다. 화면은 50개씩 나누어 표시하지만 저장 개수 제한은 없습니다. 검색, 종류 필터, CSV 전체 내보내기, JSON 백업·가져오기를 지원합니다.
* 과거 기록: 구버전은 최근 5개만 브라우저에 저장했습니다. 같은 브라우저와 주소에서 남아 있는 기록을 자동으로 가져오며 과거 날짜는 알 수 없습니다. 이미 지워진 이전 기록을 프로그램만으로 복원할 수는 없습니다.
* Windows 최근 영상: Windows 최근 항목에 남은 영상 바로가기를 참고 기록으로 가져옵니다. 다른 프로그램에서 연 영상도 포함될 수 있고 시각은 바로가기 수정 시각입니다. VideoRandom 전체 실행 기록과 같지는 않습니다.
* 기록 저장 위치: %LOCALAPPDATA%\VideoRandom\catalog\history\events.jsonl 파일에 계속 누적합니다. 브라우저 기록 삭제나 프로그램 업데이트에도 유지됩니다. 재생 기록은 기본 플레이어를 실행했다는 뜻이며 끝까지 시청했다는 뜻은 아닙니다.
* 영상 내용 목록: 폴더를 스캔한 다음 화면 아래 목록에서 영상을 선택하고 [선택 영상 분석]을 누르세요.
* 뽑은 영상 자동 분석: 기본으로 켜져 있습니다. 무작위로 뽑힌 영상은 현재 분석 방식으로 자동 처리되며 [선택 영상 분석]을 따로 누르지 않아도 됩니다. 완료된 영상은 저장 결과를 재사용하고, 분석 중이거나 대기 중인 영상은 중복 추가하지 않습니다. 여러 영상을 뽑으면 한 개씩 순서대로 분석합니다.
* 자동 분석 대기: 대기 목록과 저장된 서버 연결은 이 PC에서 다시 불러옵니다. 한 번 [연결 확인]에 성공하면 다음 실행과 업데이트에서는 주소와 코드를 다시 입력하지 않아도 됩니다. 연결 준비가 되지 않았을 때는 대기 안내가 표시됩니다. 자동 분석을 끄면 대기를 잠시 멈추고, 현재 실행 중인 분석은 계속됩니다. 오류나 중지로 멈춘 경우 [설정 적용 · 대기 분석 계속]을 누르세요.
* 영상 목록 정렬: [정렬 순서]에서 분석 완료 우선, 최근 분석순, 파일명 오름차순·내림차순, 경로·드라이브순을 선택하세요. 기본은 분석 완료 우선이며 같은 상태에서는 최근 저장한 분석이 먼저 표시됩니다. 선택한 정렬은 같은 브라우저에서 기억합니다. 저장 내용이나 원본 영상 파일은 바뀌지 않습니다.
* 로컬 분석: API 키 없이 대표 이미지 10장과 읽을 수 있는 자막을 추출합니다. 줄거리와 라벨은 직접 입력할 수 있습니다.
* Codex 분석: [이 PC에서 Codex 분석]을 선택하면 API 키 없이 로그인된 Codex로 줄거리·대사 요약·라벨을 생성합니다. 자막이 없으면 로컬 음성 인식으로 전체 대사를 추출합니다. 대표 이미지와 대사는 Codex 요약 과정에서 ChatGPT로 전송되며 계정의 Codex 사용량 한도가 적용됩니다.
* 다른 PC 연결: 이 PC에서 [이 PC를 분석 서버로 사용]을 펼쳐 [서버 시작]을 누르세요. 다른 PC에서 [분석 서버로 보내기]를 선택하고 표시된 서버 주소와 연결 코드를 입력한 뒤 [연결 확인]을 누르세요. 다른 PC에서는 Codex나 Python을 설치하지 않아도 됩니다.
* 같은 공유기: 랜선/Wi-Fi 여부는 상관없으며 같은 공유기의 내부망이면 연결할 수 있습니다. 기본 서버 포트는 3001입니다. 연결이 차단되면 개인 네트워크 방화벽 또는 게스트 Wi-Fi 격리를 확인하세요. 서버 PC와 프로그램은 켜져 있어야 합니다. 서버의 연결 코드와 서버 시작 설정은 재시작 후에도 유지됩니다.
* 업데이트와 연결 유지: 이전 프로그램을 종료하고 새 실행 파일로 교체하세요. 연결 정보는 실행 파일과 별도로 %LOCALAPPDATA%\VideoRandom\catalog에 암호화해 보관하며 브라우저 저장소나 분석 결과에는 코드를 넣지 않습니다. 1.4.0까지의 버전은 코드를 저장하지 않았으므로 이미 종료했다면 새 버전에서 한 번 [연결 확인]을 해야 합니다. 그 이후 업데이트는 저장된 연결을 자동으로 복원합니다. [저장된 연결 지우기]로 다른 서버 연결을 준비할 수 있습니다.
* 대표 이미지: 영상 전체 길이에 맞춰 같은 간격으로 10장을 자동 추출합니다. 30분 영상은 약 3분 간격, 2시간 영상은 약 12분 간격입니다. 시각을 직접 입력할 필요가 없고 이미지 수만 1~20장으로 조절할 수 있습니다.
* 엑셀 저장: 분석한 영상을 선택하고 엑셀 저장 버튼을 누르세요. 영상 목록, 이미지가 직접 삽입된 장면 이미지, 시간 표시가 붙은 전체 대사 시트가 있는 .xlsx 파일로 저장됩니다.
* 결과 수정·보관: 상세 화면에서 줄거리와 라벨을 수정할 수 있습니다. 서버에 분석을 보내도 완료된 줄거리·대사·이미지는 영상을 선택한 PC의 %LOCALAPPDATA%\VideoRandom\catalog에 자동 저장됩니다. 다시 실행하면 스캔 없이 표시되고, 저장 결과 보기와 엑셀 저장은 분석 서버가 꺼져 있어도 가능합니다. 진행 중인 분석은 결과 수신과 저장이 끝날 때까지 프로그램을 켜 두세요. 재분석이 실패하거나 중지되어도 이전 완료 결과는 유지합니다.
* 중지: 분석 중 [중지] 버튼을 누르면 그때까지 추출한 결과를 보관합니다. 일부 결과에는 미완료 경고가 표시됩니다.
* 드라이브 자동 감지: 꽂아두신 외장하드 드라이브(예: D:\, E:\)가 좌측 드라이브 선택 영역에 자동으로 표시됩니다. 클릭 한 번으로 경로 입력란을 채울 수 있습니다.
* 제외할 폴더 및 경로 설정: 스캔 시 제외하고 싶은 폴더명(예: Cache, Temp) 또는 경로(예: D:\huge_folder)를 입력하여 스캔 대상에서 제외할 수 있습니다 (ex) Cache, Folder\,Name, D:\huge_folder). 입력한 설정은 자동으로 저장됩니다.
* 포맷 필터: 스캔 후 원하는 영상 확장자(.mp4, .mkv 등)만 선택해 목록을 필터링할 수 있습니다.
* 선택한 포맷 제외하기: 룰렛을 돌릴 때 특정 확장자를 룰렛 대상에서 제외하고 뽑기를 진행할 수 있습니다.
* 즉시 재생: 뽑기에서 뽑힌 영상은 [즉시 재생하기] 버튼을 누르면 윈도우 기본 미디어 플레이어로 즉시 자동 실행됩니다.
* 폴더 위치 열기: [폴더 위치 열기] 버튼을 누르면 윈도우 탐색기가 열리면서, 당첨된 영상 파일이 위치한 폴더로 바로 이동하고 해당 파일이 파랗게 '선택(Highlight)'되어 있어 아주 편리합니다.
* 프로그램 종료: 실행 중인 검은색 CMD 창을 닫아주시면 깔끔하게 서버와 프로그램이 종료됩니다.
